# OpenRC

OpenRC is a browser-based air traffic control simulator focused on realistic controller decision-making, deterministic AI-controlled adjacent positions, and a clean radar-first interface.

## Status

Early vertical-slice development. The first milestone targets a playable Approach/Departure + Center experience with deterministic aircraft physics, handoffs, procedure following, compact flight strips, separation alerts, terrain display modes, and custom waypoint editing.

## Product rule

Prefer better simulation behavior over visual complexity, and prefer a clean UI controlling realistic systems over a difficult UI that merely looks realistic.
